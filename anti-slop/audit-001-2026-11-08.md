## Executive Summary

This audit evaluates the BrandMuse repository against the Anti-Slop framework to eliminate generic AI-generated artifacts, ungrounded UI patterns, dead controls, and clichéd copywriting. 

Overall, BrandMuse possesses a high baseline: the backend implements strict RAG grounding with delimiter security (`<untrusted_brand_guideline_context>`), explicit citations, session isolation, and database-persisted rate limits. The frontend uses a disciplined monochrome palette following the Behance AI Assistant SaaS reference.

However, several stereotypical AI-generated artifacts remain:
1. **Dead interactive controls** (a non-functional voice `<Mic>` button copied from visual mockups).
2. **Fabricated user status** (an assumed avatar with a fake "online" green beacon on an anonymous session app).
3. **Pervasive `<Sparkles>` icon usage** (relied on across 4 separate pages as the default "AI" signifier).
4. **Pill-shape radius overuse** (`rounded-full` applied indiscriminately across buttons, inputs, pills, and badges).
5. **Missing error state** in the Asset Gallery.
6. **Code comment clutter** (repeated decorative banner separators and workflow narration in tests).
7. **Unconstrained prompt outputs** (absence of negative constraints against chatbot conversational preamble and buzzword-laden social copy).

### Group 4: Non-UI & Functional Hygiene Audit (Temuan [22] s/d [26]) — [STATUS: RESOLVED]

#### [22] Client Stream Reader — Raw JSON Token Slicing [RESOLVED]
- **File:** `apps/web/src/pages/AskPage.tsx:258-270`
- **Violation:** SSE event stream reader appended `nextLine.slice(6)` without parsing `data: {"token": "..."}`, causing raw JSON fragments to display in live assistant bubbles.
- **Resolution:** Added safe JSON parsing `JSON.parse(rawData)?.token ?? rawData` with string fallback. UI visual styling remains 100% untouched.

#### [23] Fetch Mutator — Dropped Multipart Form Boundary [RESOLVED]
- **File:** `apps/web/src/api/mutator.ts:73`
- **Violation:** Orval set `Content-Type: multipart/form-data` statically without MIME boundary parameter, causing browser `fetch()` to omit multipart boundary on file uploads.
- **Resolution:** Applied Modern Web fetch rule: `headers.delete("Content-Type")` when `config.data instanceof FormData`, enabling the browser to generate the boundary automatically.

#### [24] Prompt Security — Delimiter Breakout in Ontology Extraction [RESOLVED]
- **File:** `apps/api/app/rag/ontology.py:86`
- **Violation:** Context was enclosed in ungrounded `<guideline_context>` without `sanitize_untrusted_text()`, opening risk of delimiter breakout.
- **Resolution:** Converted to canonical `<untrusted_brand_guideline_context>` security directive paired with `sanitize_untrusted_text()`.

#### [25] Prompt Guardrail — Hallucinated Attributes in Ontology [RESOLVED]
- **File:** `apps/api/app/rag/ontology.py:44-46`
- **Violation:** LLM prompt did not explicitly constrain missing attributes to `null` or empty lists.
- **Resolution:** Added strict negative constraint forbidding extrapolation or hallucination of missing color hexes, font rules, or taglines.

#### [26] Reliability — Unbounded Polling Loop in Image Provider [RESOLVED]
- **File:** `apps/api/app/providers/image.py:168-175`
- **Violation:** While loop in `ReplicateImageProvider` polled status indefinitely without a maximum iteration bound.
- **Resolution:** Added bounded loop with `max_attempts = 45` (90s limit) raising `IMAGE_GENERATION_TIMEOUT`.
